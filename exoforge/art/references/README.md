# Style references

The owner's style images live here as `ref-01.jpg` … `ref-05.jpg`. They are third-party game art, used only as style
references, so they are **not committed** (this repository is public). Each new session needs them dropped in again
(or attached to the first message) before any visual work.

| File | What it shows | Use it for (SPEC Part B §2) |
|---|---|---|
| ref-01.jpg | A glossy stylised-3D heroine with a blaster on flat blue (stands in for the "two characters with a pig" image the spec names) | rendering quality only: soft painted 3D shading, strong brows, glossy materials |
| ref-02.jpg | Three villager portraits with a chunky title | cloth, rope and leather materials, muted earthy palette on dark backdrops, chunky outlined title lettering |
| ref-03.jpg | A craftsman planing wood at a sunny workbench | the Workshop mood: warm golden light, pegboard of tools, shavings. Its light comes from the upper right; we keep the upper-left key light |
| ref-04.jpg | A hero upgrade screen | the UI language: wood panel with gold trim, stat rows `old → new ↑`, blue % bar, glossy yellow button, round portraits |
| ref-05.jpg | A squad battle | in-game readability: bright characters over a quieter ground, coloured bars, star cards, a curved hint arrow |
