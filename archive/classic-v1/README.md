# Night Express Classic (v1)

The game as it stood at the end of session 11, kept as a backup before the diagonal lakeside, night look
and carriage luxury tiers rework (session 12).

- **Play it:** open `night-express-classic.html` in any browser (one self-contained file, works offline),
  or the published copy: https://claude.ai/artifact/63KiqpMv1nURaXatrpm5Mp
- **Its source:** commit `8a876f9` on this branch ("Show, don't tell: icon-first HUD, ringing
  celebrations, earlier Cosy refits").
  - Look at it without touching the current work: `git worktree add ../night-express-classic 8a876f9`
  - Go back to it for good: `git checkout 8a876f9 -- . && git commit -m "Restore classic v1"` (the new
    version stays in history and can be restored the same way).
