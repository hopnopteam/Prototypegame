# Detail textures (session 49)

`detail.jpg` is built by `scripts/assets/build_textures.py` from these Poly Haven textures (all CC0 1.0,
https://polyhaven.com/license), each divided by its own average colour so it only adds grain and variation over the
game's own colours. The 1K sources are fetched into `src/` (git-ignored) when the script runs.

| Layer | Poly Haven texture | Used for |
|---|---|---|
| woodWorn | wood_table_worn | run-down floorboards |
| wood | oak_veneer_01 | repaired floorboards |
| woodPolished | wood_table_001 | polished boards (Cosy) |
| herringbone | herringbone_parquet | Luxurious floors |
| wool | rough_linen | carpets and rugs |
| grass | leafy_grass | the countryside ground |
| ground | forrest_ground_01 | (spare: paths, later) |
| paving | patio_tiles | the station platform's stone flags (session 51b) |
